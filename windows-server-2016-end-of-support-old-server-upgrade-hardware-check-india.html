Windows Server 2016 Ends Jan 2027: Will Your Server Upgrade?

Quick answer: Microsoft's lifecycle page lists the end of extended support for Windows Server 2016 as 12 January 2027. Servers keep running after that, but Microsoft stops publishing security updates. Microsoft's upgrade table lists direct in-place upgrades from 2016 to 2019, 2022 and 2025. Before you upgrade an older server, check the processor against Microsoft's requirements, the server maker's support list for your exact model, and your licences.

This page covers the hardware side. For the complete plan including the options and a 12-week timeline, read Serverwale's Windows Server 2016 end-of-support guide. Dates and support lists change, and this is not licensing advice.

Microsoft also notes that, starting with Windows Server 2025, a nonclustered system can upgrade up to four versions at a time, and that you should back up before any in-place upgrade, clean install or migration. If you are moving to new hardware, Microsoft says migration is the better method.

Will an older server's processor pass?

Microsoft's hardware requirements list these as the minimum processor features: a 1.4 GHz 64-bit processor, x64 instruction set, NX and DEP, CMPXCHG16b, LAHF/SAHF and PrefetchW, second level address translation (EPT or NPT), SSE4.2 and POPCNT. Use Microsoft's Coreinfo tool to see what your processor supports. Check your exact CPU model before you buy; our guides to Intel Xeon processors, HP ProLiant Gen9 vs Gen10 and Dell PowerEdge R630 to R740 explain the generations.

TPM, Secure Boot and firmware

Microsoft says a TPM is needed only for certain features such as BitLocker, and that any TPM present must be 2.0. Secured-core server needs more: DMA remapping (Intel VT-d or AMD-Vi), Kernel DMA Protection, DRTM, TPM 2.0, Secure Boot and virtualization-based security. UEFI 2.3.1c firmware is listed for Secure Boot. Update firmware before an upgrade; read our firmware and BIOS update guide.

What to check before upgrading an older server

  • The server maker's support list. Dell, HPE and Lenovo publish which operating-system versions they support on each model. An older model is not automatically supported on the newest Windows Server.
  • Drivers. Storage controllers, network cards and management firmware need drivers for the new version.
  • Memory and storage. Microsoft says to consult each role's documentation for resource needs, so check the roles you run. See the server RAM buying guide.
  • Licences. Each new version needs its own licence. Read server licensing: per core vs per socket.
  • A backup. A restore-tested backup before any upgrade; see RAID is not a backup.
  • Warranty and parts. Check how long parts and support will last; see the refurbished server lifespan guide and AMC cost.

Frequently Asked Questions

When does Windows Server 2016 support end? Microsoft's lifecycle page lists mainstream support as ended on 11 January 2022 and extended support as ending on 12 January 2027. After that date Microsoft stops publishing free security updates for it.

Can I upgrade Windows Server 2016 directly to 2025? Microsoft's upgrade-path table lists in-place upgrade from Windows Server 2016 to 2019, 2022 and 2025 as supported. Each upgrade needs its own licence, and your hardware must work with the new version, so check the server maker's support list for your exact model first.

What CPU does Windows Server need? Microsoft's hardware requirements list a 1.4 GHz 64-bit processor with x64 instructions, NX and DEP, CMPXCHG16b, LAHF/SAHF and PrefetchW, second level address translation (EPT or NPT), SSE4.2 and POPCNT. Microsoft suggests the Coreinfo tool to check what a processor supports.

Do I need TPM 2.0 for Windows Server? Microsoft lists TPM as required only for certain features, such as BitLocker Drive Encryption, and says a TPM that is present must be version 2.0. Secured-core server needs additional hardware features. Check which features you plan to use.

Should I upgrade my old server or replace it? If the server's maker lists support for the new Windows Server version and the hardware is healthy, an in-place upgrade or a clean install can be enough. If the model is not on the support list, or the server is slow, small on memory or out of warranty, moving the workload to a newer refurbished or new server is often the cleaner path. Compare both options for your workload.
